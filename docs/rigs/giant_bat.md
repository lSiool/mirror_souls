# Риг огромной летучей мыши (вторая форма вампира)

Для 3D-художника и для подбора анимаций. Дизайн приёма — `GAME_DESIGN.md` §6.3 («Мышь»), код — `actors/enemies/giant_bat.gd` (graybox на том же скелете), снимки рига — `tools/characters/vampire_snapshot.tscn` (кадры `r1_rest`…`r4_swoop_claws`).

## Идея

Мышь антропоморфная, как у Дракулы в «Ван Хельсинге»: тело и ноги почти человеческие, **руки стали крыльями, пальцы — спицами перепонки**. Поэтому скелет — **гуманоидный профиль Godot** (`SkeletonProfileHumanoid`, те же имена костей, что у манекена героя), просто с очень длинными руками и пальцами:

| Кость профиля | У мыши |
|---|---|
| `Hips`, `Spine`, `Chest`, `UpperChest`, `Neck`, `Head`, `Jaw` | тело, шея, голова, нижняя челюсть (крик, укус) |
| `LeftShoulder` / `LeftUpperArm` / `LeftLowerArm` / `LeftHand` | плечо, плечевая кость, предплечье, запястье крыла |
| `LeftThumbProximal…Distal` | короткий коготь на сгибе крыла |
| `LeftIndex…`, `LeftMiddle…`, `LeftRing…`, `LeftLittle…` (`Proximal`, `Intermediate`, `Distal`) | четыре спицы перепонки: передний край, самая длинная, задняя, ближняя к телу |
| `LeftUpperLeg` / `LeftLowerLeg` / `LeftFoot` / `LeftToes` | ноги с когтями; к щиколотке крепится задний край перепонки |
| `Right…` | то же зеркально |

Хвоста и ушей костями нет (уши — часть головы). Если художнику нужно больше костей (хвост, уши, складки перепонки) — можно добавить, но имена из таблицы должны остаться.

## Покой (rest pose)

- **T-поза:** стоит, смотрит в **+Z**, верх — **+Y**, левое крыло — в **+X**.
- Крылья раскинуты прямо в стороны, перепонка — в плоскости XY (как кадр `r1_rest`), ноги прямо вниз.
- Повороты костей в покое — по возможности нулевые (как у graybox), масштаб костей 1.
- Размер graybox: от бёдер до макушки ~0.9 м, ноги ~0.8 м, **размах ~4.8 м**. В игре мышь может быть масштабирована; пропорции — по концепту автора.

## Перепонка

У graybox перепонка строится каждый кадр по костям: плечо → локоть → кисть → кончики спиц (фестоны между ними провисают к кисти) → щиколотка → бедро, и между ног — хвостовая перепонка. В модели перепонка — обычная скиновая сетка, привязанная к спицам, предплечью, телу и голени; важно, чтобы при складывании пальцев она складывалась, а не рвалась (веса по спицам плавные).

## Как модель заменит graybox

1. Модель (glTF/FBX) со скелетом из таблицы, в T-позе покоя.
2. При импорте Godot — `BoneMap` на `SkeletonProfileHumanoid` (как у манекена, `tools/characters/setup_mannequin.py`); кости крыльев лягут на пальцы и руки сами.
3. `GiantBat` вместо graybox-деталей показывает модель; процедурные позы (`_pose()`: взмах, складывание, вис, пике, когти, пасть) работают на тех же именах костей.
4. Когда появятся анимации — клипы играются на том же скелете, а процедурные позы остаются поверх как добавка (наклон по скорости, крен к камере) или выключаются.

## Какие клипы нужны (первая очередь)

| Клип | Что делает | Где в бою |
|---|---|---|
| `Fly_Loop` | машет в горизонтальном полёте | набор высоты, перелёт |
| `Hover_Loop` | висит стоймя, частые взмахи, ноги свисают | замах пике (перед ним — крик) |
| `Glide` / `Dive` | крылья поджаты назад, пикирует | пике сквозь героя |
| `Grab` | на пике выносит ноги когтями вперёд | низшая точка пике |
| `Screech` | пасть раскрыта, голова вперёд | телеграф пике |
| `Land` / `TakeOff` | касание земли и взлёт | посадка перед превращением, вылет из тьмы |
| `Hit` | вздрагивает в воздухе | удар по мыши |
| `Death_Air` | падает, крылья комкаются | смерть в облике мыши (вампир становится человеком в падении) |

Вторая очередь (если мышь будет делать больше): ползание по земле на сгибах крыльев, висение вниз головой под потолком, удар крылом.

## Где искать анимации

Mixamo не подойдёт для полёта: там только человеческие движения. Варианты, от лучшего к худшему:

1. **Готовые крылатые существа с анимациями** — ищи по запросам `gargoyle`, `werebat`, `vampire bat creature`, `winged demon`, `harpy`, `dragon` (у дракона то же строение крыла: плечо, предплечье, спицы-пальцы, перепонка). Где: **Fab** (бывший Unreal Marketplace, много бесплатного раз в месяц), **Unity Asset Store**, **Sketchfab** (фильтр «Animated» + «Downloadable», лицензия CC-BY или CC0), **CGTrader / TurboSquid** (фильтр rigged + animated). Скачивать **FBX или glTF** с анимациями. Даже если модель не та — её клипы можно переложить на наш риг, если кости похожи.
2. **Человеческие клипы для тела** из Mixamo: рёв, крик, удар, падение, ползание (`Mutant Roaring`, `Zombie Scream`, `Crawl`, `Falling`). Тело у мыши гуманоидное — эти клипы лягут на неё через гуманоидный профиль; крыльями тогда машет процедурный код.
3. **Анимирует художник**, который делает модель, — по списку клипов выше; это самый надёжный путь для `Fly_Loop` и `Hover_Loop`.
4. Пока ничего нет — работает процедурная анимация graybox (сейчас в игре).

Что прислать: FBX/glTF в `assets/characters/giant_bat/` (не в `art/`), лицензию и ссылку на источник — в `LICENSE.txt` рядом.
