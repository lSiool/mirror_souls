# «Осколки» — каталог персонажей

Все персонажи игры: герой, враги, боссы, дружественные NPC. Здесь — **кто есть кто и где что лежит**.
Механика боя (стойкость, тайминги, приёмы) живёт в `GAME_DESIGN.md`; карточка на неё ссылается, а не повторяет.

**Как пополнять:** новый персонаж — строка в нужной таблице + карточка по шаблону [`_template.md`](_template.md).
Концепт-арт — в `art/concepts/characters/` (латинские имена, префикс — id персонажа). Генерация — по `docs/ART_PIPELINE.md`, имя ассета `char_<id>`.

**Статусы:** идея → концепт (есть утверждённая картинка) → graybox (есть в игре на примитивах или манекене) → модель (3D в `assets/characters/`) → готов (модель, риг, анимации).

## Правило трёх стадий (решено 2026-11-15)
Почти у каждого обычного врага **три стадии развития или три вариации** — это три отдельных врага в игре, от слабого к сильному.
**Третья, сильнейшая стадия — босс** (решено 2026-11-15). Оборотни: недавно обращённый → обычный (мини-босс) → альфа (босс).
Вампиры: недавно обращённый → обычный вампир → Древний Вампир (босс). Особые силы — у старших стадий: обычный вампир, например, в летучую мышь не превращается.
Внутри стадии бывают внешние варианты (одежда, пол) без разницы в бою — как у недавно обращённых вампиров.
