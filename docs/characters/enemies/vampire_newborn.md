# Недавно обращённый вампир (`vampire_newborn`)

**Тип:** враг · **Семейство и стадия:** вампиры, 1 из 3 · **Класс:** вампир · **Статус:** концепт

## Кто это
Неопытный, только что обращённый вампир. Стадии семейства: недавно обращённый → вампир (`vampire`) → Древний Вампир (`vampire_ancient`, босс).

## Где встречается
Не решено.

## Как выглядит
Бледная кожа с трещинами, клыки, заострённые уши, когти, кровь у рта; потрёпанная дорогая одежда с бордовой подкладкой.
Три внешних варианта без разницы в бою:
- `art/concepts/characters/vampire_newborn_1.png` — мужчина в камзоле с высоким воротником;
- `art/concepts/characters/vampire_newborn_2.png` — мужчина, другая одежда;
- `art/concepts/characters/vampire_newborn_3_female.png` — женщина.

Концепты на белом фоне; для 3D через TRELLIS это подходит.

## Бой / поведение
Не задано. Общее для вампиров: святая вода жжёт, слепота дезориентирует (§6.2, §6.3); в зеркале не отражается (§6.5).
