# «Осколки» — план звуков для Прототипа 01 (одна комната)

> Цель звука на этом этапе — не красота, а **отклик**: чтобы удар, перекат, стекло и зеркало
> «чувствовались» на серых кубах (Гейт 1). Поэтому берём минимум, но по каждому событию — несколько вариантов.
> Приоритеты: **P0** — нужно для прототипа, **P1** — добавим к M2/M4, **P2** — потом.

---

## 1. Формат файлов

| Что | Формат | Параметры |
|---|---|---|
| Короткие SFX (удары, шаги, стекло) | **WAV** | 44.1 кГц, 16 бит (рабочие исходники — 24 бит), **моно** |
| Длинные петли (комната, гул зеркала) | **OGG Vorbis** | 44.1 кГц, стерео, бесшовная петля |
| Музыка (потом) | OGG | стерео |

- **Моно** для SFX: позиционирование делает движок (`AudioStreamPlayer3D`), стерео-эффекты в файле только мешают.
- **Сухие**: без вшитой реверберации — реверб добавляет Godot по шине (разный для мира и отражения!).
- **Пик −3…−1 dBFS**, одинаковая «громкость на слух» внутри группы; тишина в начале обрезана (удар должен стартовать в 0–5 мс).
- **Фейд 2–5 мс** в начале и конце, чтобы не было щелчков.
- MP3 только как *источник* для нарезки. В проект кладём WAV/OGG.

## 2. Структура папок и имена

```text
res://audio/
├── sfx/
│   ├── player/    player_step_floor_01.wav …
│   ├── combat/    sword_hit_body_01.wav …
│   ├── glass/     glass_break_01.wav …
│   ├── mirror/
│   ├── world/     chest_open_01.wav …
│   └── enemy/
├── loops/         room_tone.ogg, mirror_idle.ogg, reflection_ambience.ogg
├── modal/         запечённые модальные звуки (bake)
└── _source/       исходники и manifest.csv (в проект не импортировать)
```

Имя: `группа_событие[_уточнение]_NN.wav`, нумерация вариантов с `_01`. Одно событие — один набор вариантов (5–6 для частых, 2–3 для редких).

**Итого P0: ~30 событий, ~80 файлов.** Это нормально для первого вечера «поиска», собирать не обязательно всё сразу: начните с боя (меч, стекло, шаги) — это Гейт 1.

### Принципы слоёв

Один «хороший» удар = 3–4 слоя, лежащих отдельными файлами или собранных в Reaper/FMOD:
`transient` (первые 10–30 мс, атака) + `body` (материал) + `tail` (звон/эхо) + `sub` (низ для тяжёлого).
Для P0 достаточно 1–2 слоёв, но искать полезно сразу «удар» и «звон» раздельно.

### Идея языка бликов

`glass_glint` — одна и та же чистая нота у чистого стекла; у ловушки (красные прожилки) — тот же звук, но **на полтона ниже/с лёгкой «грязью»**. Подсказка в звуке есть всегда, но тонкая — так «честность стекла» работает ещё и ухом.

## 4. Как работать с найденным (включая одну большую mp3 с кучей звуков)

1. **Складывайте исходники в `_source/` как есть** и ведите `manifest.csv`: `файл, откуда (URL), автор, лицензия, можно ли в коммерцию`. Это важно для Steam: «бесплатно скачано» ≠ «можно в игру».
2. **Одна mp3 с десятками звуков** — нормальный случай. Её нарезают по паузам/пикам громкости (детектор тишины и onset-детектор), каждый кусок получает временное имя `src_001`, `src_002`…
3. **Разбор — классификация и именование.** Для каждого куска считаются: длительность, пик, длительность затухания, доминирующие частоты, «яркость» спектра, спектрограмма. По этому можно сгруппировать «короткий щелчок / звон / шорох / удар», но **слушать и выбирать на слух придётся вам**: я не слышу звук, я работаю с числами и картинками спектра.
4. **Обработка:** обрезать тишину, фейд, нормализация по группе, конверт в моно WAV 44.1/16, переименование по схеме §2.
5. **Результат:** папка `sfx/…` с WAV по схеме + обновлённый `manifest.csv` + (по желанию) `.tres`-ресурсы с группами вариантов для round-robin.

### Что мне присылать
- Сами файлы (mp3/wav/ogg) прикреплением к чату, лучше пачками по группе (напр., «всё про меч»).
- К каждой пачке — одной строкой: что это и откуда (для лицензии).
- Если в mp3 уже есть таймкоды/список звуков — приложите, нарезка получится точнее.

### Что я верну
- Нарезанные и отнормализованные WAV, разложенные по §2.
- Таблицу: какой кусок что содержит (длительность, яркость, затухание) — чтобы вам было проще выбирать на слух.
- Для металла и стекла: **оценку мод из реальной записи** (частоты и затухания пиков спектра) — их можно вставить в `ModalMaterial` и получить параметрический вариант «вашего» звука.

### Если mp3-композиция — это музыка или смесь с музыкой
Нарезать на отдельные SFX не получится: музыка и эффекты уже смешаны. Для SFX нужны чистые записи; такие куски лучше пометить как «музыка/атмосфера» и использовать как референс настроения.

## 5. Где брать (кратко)

### Что решили для прототипа (2026-10-21)
- **Kenney (CC0)** — основной источник сейчас: паки Impact Sounds, RPG Audio, Interface Sounds. Звуки героя — только записи.
- **Стекло — мрачнее**: тяжёлое стекло Kenney ниже по высоте и через lowpass, под ним — низкий хвост модального синтеза. Не «звон бокала».
- **Кандидаты** собирает `tools/sound/make_candidates.py` (numpy + ffmpeg): по 3–4 на событие, выбор — на странице с плеерами. Тот же скрипт с `--bank событие=буква` рендерит банк вариантов в `audio/sfx/`.
- **Freesound** из облачной сессии недоступен: сайт отвечает 403 на любой запрос с IP облака, ключ ни при чём. Работаем с ним из локальной сессии дома: ключ — в переменной окружения `FREESOUND_API_KEY`, не в файлах. Превью качаются по ключу; оригиналы требуют одной OAuth2-авторизации в браузере.
- **Запасной источник** — `opengameart.org` (фильтр CC0), если его разрешить в сетевых настройках окружения.

- **Sonniss GameAudioGDC** — ежегодные бесплатные паки для коммерческого использования (меч, металл, удары, стекло ищем по названиям паков).
- **Freesound** — бесплатно, но лицензии разные (берите CC0 / CC-BY, избегайте NC).
- **A Sound Effect, BOOM Library, Pro Sound Effects** — платные профессиональные паки (когда пойдёт на срез).
- **Модальный синтезатор** (`modal_synth.gd`) — для звона металла и стекла, параметрически от силы и точки удара.
