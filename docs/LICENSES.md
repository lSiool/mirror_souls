# Лицензии инструментов и ассетов

Правило с 2026-11-16: пока игра делается для себя, но берём только то, что разрешено и в платной игре, — чтобы при решении продавать ничего не переделывать.
Новый инструмент или источник ассетов — сначала лицензия, потом в работу; строка сюда.
Проверено по открытым источникам 2026-11-16; это не юридическая консультация — перед продажей перечитать текущие условия.

## В работе

| Что | Для чего | Лицензия | Можно в платной игре | Обязанности |
|---|---|---|---|---|
| FLUX 3 Image Klein (`flux3-image-klein`) | Концепты, варианты A и B в gen3 | FLUX Kommunity License | Да, пока годовой доход < $5 млн | Разрешение — на картинки, не на распространение модели; при доходе выше — платная лицензия BFL. Есть требования о проверке и раскрытии — перечитать перед продажей |
| FLUX.2 Klein 4B (`flux-2-klein-4b-fp8`, лежит в ComfyUI) | Сейчас не используется | Apache 2.0 | Да | — |
| Z-Image Turbo | Варианты C и D в gen3 | Apache 2.0 | Да | — |
| TRELLIS.2 (Microsoft) | Картинка → 3D-модель | MIT | Да (модели — наши) | Сохранять текст MIT, если распространяем сам код (мы — нет) |
| Mixamo (Adobe) | Клипы анимаций | Бесплатно, без отчислений | Да | Нельзя выкладывать исходные FBX — поэтому `assets/characters/anims/mixamo/` в `.gitignore`; в сборке игры клипы можно |
| Quaternius (UAL, манекен) | Клипы и манекен | CC0 | Да | — |
| Kenney | Звуки ударов, разлома | CC0 | Да | — |
| Freesound | Звуки | CC0 или CC-BY (3.0/4.0) | Да | **CC-BY — автор в титрах игры.** Список — `audio/_source/manifest.csv` (колонки «автор» и «лицензия») |

## Захват движения с видео (выбор 2026-11-16)

| Что | Можно в платной игре | Заметки |
|---|---|---|
| Rokoko Vision | Да, даже на бесплатном тарифе | Бесплатно — ролики до ~15 с, ~30 с обработки в месяц; безлимит ~£50/мес. **Первый выбор** |
| DeepMotion | Только на платном (~$9–15/мес) | Бесплатные 60 с в месяц — некоммерческие |
| FreeMoCap | Да (AGPL — на программу, анимации наши) | Локально, бесплатно, но нужны 2–3 откалиброванные камеры |
| Move One (Move.ai) | Не ясно | От $18/мес; условия коммерции не нашёл |
| GVHMR, WHAM | **Нет** | Веса — только исследования; формат тела SMPL для коммерции — платная лицензия Meshcapade (от €1 500/год). Не брать |
| HY-Motion, Kimodo (анимация по тексту) | — | Не запустятся на 8 ГБ видеопамяти (24 и ~17 ГБ) |
| Cascadeur | Indie (~$8/мес) — да; бесплатная — нет | Бесплатная без экспорта FBX и некоммерческая |

## Авториг и анимация по тексту/видео (проверено 2026-11-16)

| Что | Можно в платной игре | Заметки |
|---|---|---|
| Mixamo — авториг (загрузить свою модель) | Да (условия Mixamo) | Кости сразу с именами `mixamorig_*` — наша карта костей. Только гуманоиды, модель в A/T-позе, руки отдельно от тела. **Первый выбор для людей и оборотня** |
| UniRig (VAST-AI) | Да — MIT на код и веса (по сторонним источникам; обучен на Articulation-XL2.0, CC-BY-4.0 — указать в титрах). Перечитать LICENSE перед установкой | Локально, ~8 ГБ видеопамяти. Любые существа (мышь, ползун). Веса скиннинга, по некоторым данным, выложены не все — проверить |
| HY-Motion 1.0 (Tencent), текст → движение | Серая зона | Скелет SMPL-H (семейство SMPL); локально не запустится (24 ГБ). Не брать, пока не прояснится |
| Grok Imagine (xAI), видео по тексту | По сторонним данным — да, на платном тарифе; гарантий от исков xAI не даёт | Это видео, не анимация: только как ролик для Rokoko Vision. Бесплатное — с водяным знаком |
