# art/ — исходники арта

Godot эту папку не видит (`.gdignore`). Всё, что идёт в игру, лежит в `assets/`.

| Папка / файл | Что там | В git |
|---|---|---|
| `STYLE_BIBLE.md` | Библия стиля: палитры, свет, материалы, профили генерации | да |
| `FIXED_PREFIX.md`, `FIXED_ASSETS.md` | Тексты стиля для запросов и шаблоны | да |
| `LOCATIONS.md` | Запросы для первых локаций | да |
| `concepts/` | **Наш канон:** утверждённый концепт-арт, по нему строим уровни и модели | да |
| `concepts/characters/` | Персонажи: `<id>_sheet.png`, `<id>_front.png` … — id из [каталога персонажей](../docs/characters/README.md) | да |
| `concepts/locations/` | Локации: `village_*`, `chapel_*`, `forest_NN_*` (NN — кадр из `level_concept/`) | да |
| `concepts/key/` | Ключевые кадры и раскадровки | да |
| `concepts/props/` | Предметы | да |
| `refs/` | **Чужое, только для настроения:** кадры фильмов и игр (Mandragora), скриншоты | нет |
| `ui_source/` | Исходники интерфейса | да |

**Правила:**
- В `concepts/` — только то, что сделали мы и что автор утвердил. Имена латиницей, без пробелов.
- Черновые генерации остаются в `ComfyUI\output\mirror_souls\`; в `concepts/` переносим выбранный вариант (`docs/ART_PIPELINE.md`).
- Чужие кадры — только в `refs/`, в игру и в git не идут.
