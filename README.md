# «Осколки»

2.5D side-scroller action-roguelite в тёмном фэнтези: соулслайк-бой, уровни, которые собираются заново каждый забег, постоянный хаб с сюжетом и мета-прогрессом, зеркала, которые меняют пространство и его правила, и стекло, каждое пробитие которого — ставка.

## Идея

**Взросление.** Взросление — это ответственный шаг и тяжесть, но тяжесть особенная. В игре оно не только тема сюжета, но и механика: герой взрослеет вместе с уровнем, а в начале игрок сам выбирает, в каком возрасте (от 14–15 до 22 лет) герой отправляется в путь. Младше — быстрее и ловчее, старше — чуть медленнее и чуть сильнее удар. Зеркала показывают героя немного старше, чем он есть, — будущего себя, а Главное Зеркало в финале показывает, каким его сделал выбранный путь.

**Два ритма.** Игра чередует **забеги** внутри рушащегося отражения — скорость, стекло, падения, постоянный выбор «остановиться ради добычи или бежать дальше» — и **боевые уровни** в настоящем мире, где упор на сражение и детали локации. Как пробежал забег, так и начнётся бой. Каждый биом — три уровня (зеркальный, забег, мини-босс) и босс.

**Мета-прогресс.** Рецепты оружия открываются навсегда, ресурсы биомов копятся в хабе, часть осколков после смерти остаётся у врага — вернись и забери. В каждом биоме — свой босс.

Полный дизайн — в [GAME_DESIGN.md](GAME_DESIGN.md). Первый концепт (постоянный мир) — в [init_concept/](init_concept/).

## Как открыть

1. Установить Godot 4.7.2 (стандартная сборка, не .NET).
2. Склонировать репозиторий.
3. В Project Manager → Import → выбрать `project.godot`.
4. Главная сцена — `res://main.tscn`.

## Текущий этап

**M1 — Movement.** Прототип 01: одна комната на серых кубах (будущий первый кусок генератора) и Прототип 02: коридор-забег с волной обрушения. План — в [GAME_DESIGN.md §13](GAME_DESIGN.md#13-прототип-01--одна-комната).

Майлстоуны: M1 Movement → M2 Combat → ◆ Гейт 1 → M3 Mirror → M4 Glass → M5 Generator → ◆ Гейт 2 → M6 Meta → M7 Vertical Slice.

## Структура

```text
actors/     игрок, враги, боссы
combat/     оружие, хитбоксы, урон
world/      куски уровней (run/, fight/), зеркала, стекло, ловушки
hub/        кузница, наставники, Главное Зеркало
systems/    генератор уровней, менеджер забега, зеркала, мета-прогресс, сохранения
data/       ресурсы .tres: куски, оружие, рецепты, классы, враги, биомы
assets/     модели, текстуры, анимации
effects/    шейдеры, частицы, материалы
audio/
ui/
```

Геймплей не смешивается с конкретными кусками: системы знают *как*, куски сообщают *что*.

## Git

- Ветки: `main` — стабильное, `dev` — работа.
- Мелкие коммиты: `feat: add dash`, `fix: glass collision`, `refactor: …`, `docs: …`.
- `.godot/` и `.idea/` не коммитятся.
- Бинарные ассеты (`.glb`, текстуры, аудио) — через Git LFS.
